# Mundial 2026 Hub

Plataforma digital que centraliza la información e interacción del Mundial FIFA 2026.
Proyecto académico de Ingeniería de Software — Universidad El Bosque, 2026-1.

## Módulos del MVP
- Autenticación y gestión de acceso
- Pollas futboleras (predicciones, ranking y puntos)
- Álbum digital (colección, paquetes e intercambio de láminas)
- Monitoreo y trazabilidad con logs


## Estructura de ramas
- `main` — código verificado y listo para producción
